# 结尾页与技能小字瀑布节奏设计

## 目标

在不改变网站结构、图形和既有动效语言的前提下，让结尾页文字更从容地出现，并让 Methods & Skills 模块的小字逐行瀑布效果更容易被感知。

## 调整范围

仅调整以下两处：

1. `#contact` 结尾页三行白色主文案。
2. Methods & Skills 四张卡片内的灰色小字。

首页白色主文案、技能图标、技能标题、卡片边框、横向经历和其他瀑布文字保持现有节奏。

## 动效参数

### 结尾页

- 单行揭示时长：由 `0.8s` 调整为 `1.05s`。
- 行间错峰：由 `0.08s` 调整为 `0.14s`。
- 位移、缓动和触发方式保持不变。
- 首页继续使用原有 `0.8s / 0.08s` 参数。

### Methods & Skills 小字

- 单行过渡时长：调整为 `1.1s`。
- 初始垂直位移：由 `100%` 调整为 `125%`。
- 卡片内每行延迟间隔：由 `0.10s` 调整为 `0.15s`。
- 四张卡片之间保留轻微错峰，卡片顺序系数由 `80ms` 调整为 `110ms`。
- 第一行在卡片进入视口后 `260ms` 开始，后续各行依次增加 `150ms`。

最长的第六行将在约 `1.34s` 后开始，并在约 `2.44s` 内完成，不会让模块显得拖沓。

## 实现方式

- 为首尾白字揭示函数增加局部参数入口；首页使用默认值，结尾页传入较慢参数。
- 使用 Methods & Skills 作用域内的 CSS 覆盖小字位移、时长与延迟，不修改全站通用 `.scroll-mask-block` 规则。
- 保留现有 IntersectionObserver、一次性揭示状态和 SVG/边框动画实现。
- `prefers-reduced-motion: reduce` 下继续取消过渡并立即显示完整内容。

## 验收标准

1. 结尾页三行文字明显慢于首页对应文字，但滚动到结尾后无需等待过久。
2. 技能卡小字能清楚看到逐行上浮过程，四张卡片保持轻微斜向错峰。
3. 技能图标、标题和边框节奏不变。
4. 360–1920px 宽度下不产生重叠、裁切或横向溢出。
5. 减少动态效果模式下没有隐藏文字。
6. 自动测试明确约束局部参数，避免后续修改意外恢复为全局快速节奏。
