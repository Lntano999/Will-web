# 大一结束个人网站内容重构设计

## 目标

在不改变现有滚动、SplitText、瀑布蒙版、SVG 描边控制器和卡片进场动效逻辑的前提下，重构全站文字内容与横向经历图标，使网站准确呈现唐嘉辰完成大一后的最佳经历与清晰成长路径。

网站同时服务两个目标：

1. 呈现量化开发与金融科技后端方向的长期职业定位。
2. 作为面向所有访问者的通用个人主页，以公开成果和外部链接提供可信的能力核验入口。

数学、英语和物理家教属于专门简历中的求职信息，不在网站中设置对应入口、服务范围或行动提示。数学建模和英语演讲继续展示，是因为它们本身属于最强个人经历，而不是为了把网站包装成家教页面。

页面不做“经历堆砌”，而采用一条由小到大的问题解决主线：

**Build → Model → Field → Speak**

- 用代码把想法构建并交付。
- 用数学模型处理开放问题并带领团队协作。
- 走进县域产业现场验证判断。
- 用英语演讲和跨文化交流把复杂内容讲清楚。

## 编辑原则

- 只保留能够被作品、奖项、角色或公开报道支撑的内容。
- 结果优先于过程，事实优先于自我评价。
- 删除“卓越、极强、极致、毫秒级稳定”等缺少必要证据或显得拔高的措辞。
- 删除或降级只有参赛过程、没有明确结果的经历。
- 技术术语只保留足以证明真实实践的部分，避免个人主页变成部署日志。
- 新增内容不覆盖原版人格：网站仍然呈现开发、金融科技实践与国际表达三条长期方向。

## 横向 SVG 图标系统

四组横向经历采用用户确认的 A「统一外框系统」。原有三枚 SVG 路径与新增图标一起重构，但 side slide 的 DOM、类名、上下 `Timeline` 标签、尺寸和动画控制器全部保留。

共享规则：

- 每枚图标使用 `58 × 58` 的 `viewBox`。
- 每枚图标严格包含 4 个 `<path>`，使路径数量和绘制节奏一致。
- 每枚图标由 1 条外框路径和 3 条内部语义路径组成。
- 所有图形中心对称、白色描边、无填充，不使用 `circle`、`rect`、`mask`、滤镜或外部资源。
- SVG 继续使用 `.svg-draw` 类。现有控制器会统一设置 `stroke: #ffffff`、`strokeWidth: 1`、`fill: none`、路径长度和偏移量。
- 描边继续使用现有 `1.5s`、`power3.inOut`，不增加新的事件监听、时间轴或动画依赖。

四枚图标的几何语义：

1. **Build**：外框、中心方块、四角向中心汇聚的对角线、四边中点连接线，表示模块汇聚为可交付系统。
2. **Model**：外框、中心坐标轴、向上曲线、向下曲线，表示变量关系、模型拟合与结果检验。
3. **Field**：外框、两条纵向网格、两条横向网格、中心核验点；纵横网格分别合并在单条 path 中，总 path 数保持 4，表示下沉走访、场景覆盖和证据核验。
4. **Speak**：外框、上方双向信号曲线、下方镜像信号曲线、中心连接点，表示口语表达、倾听与跨文化沟通。

插入顺序为 Build → Model → Field → Speak。新的 Field 内容 slide 与 side slide 插入原第三组之前，原 Global Vision 内容更新为 Speak / Connect 并顺延为第四组。

## 未来项目展示与后端边界

当前网站继续采用静态优先架构。以下扩展不需要自建后端：

- 展示代码片段、项目说明、截图、视频或下载文件。
- 链接 GitHub、公开论文、新闻报道或其他项目网站。
- 嵌入不含私密密钥的纯前端交互演示。
- 为每个项目增加静态详情页。

只有出现以下需求时才考虑后端、数据库或无服务器函数：

- 保存用户提交的数据、表单记录或跨设备状态。
- 用户账户、登录、权限和个性化内容。
- 必须隐藏的 API 密钥或需要服务端签名的第三方接口。
- 支付、邮件发送、Webhook、私有数据查询或持续运行的任务。
- 浏览器无法安全或高效完成的计算。

未来扩展优先采用“静态页面 + 外部项目链接”，出现明确服务端需求后再按功能引入小型无服务器接口，不提前建设完整账户系统或通用后台。

## 断句与瀑布蒙版规则

- 每个 `.mask-line-container` 只容纳一个完整、可独立理解的短语或动作。
- 不允许浏览器在单个蒙版容器内部自动换成两行，否则下半行会被当前固定高度和 `overflow: hidden` 裁切。
- 中文行优先在逗号、顿号、并列动作边界和语义宾语之前断开，不在专有名词中间断开。
- `Cloudflare`、`CN Story`、`PPT`、`Python`、`C++`、`Git`、`LaTeX` 不拆行。
- 桌面端先按当前字号和容器宽度确定行数；移动端使用更短的同义断句。若同一组行无法同时安全覆盖两个断点，则提供桌面/移动两套可见性互斥的行容器，但共享现有 `.reveal-text-line` 动画类，不修改动画控制器。
- 新增第四组经历后，所有蒙版延时继续沿用现有 `nth-child` 规则。

## 动效与代码边界

- 不修改 GSAP 时间轴结构、duration、ease、stagger、IntersectionObserver 阈值或一次性 reveal 行为。
- 不修改预加载蒙版、页脚揭示、跑马灯、项目卡片图片裁切和导航动效。
- 允许增加第四组与现有结构相同的横向 slide pair，因为现有宽度和滚动距离是动态计算的。
- 允许替换四个 side slide 中 SVG 的 path 数据；不改变 `.svg-draw` 类、`viewBox`、外层嵌入结构或描边控制器。
- 允许为新报道链接增加静态样式、键盘焦点样式和移动端换行保护。
- 不引入新的 JavaScript 依赖、字体、图片或动画库。

## 可访问性与失败处理

- 南方+链接支持键盘聚焦，使用清晰的可见焦点样式，并在新窗口打开时通过 `aria-label` 告知用户。
- 在 SplitText 不可用或用户启用减少动态效果时，所有新文字必须保持可见，沿用现有回退规则。
- 新增第四组后，移动端仍按现有纵向可浏览方式展示，不依赖横向拖拽才能阅读。
